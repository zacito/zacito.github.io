Framework

Gravel

A reusable framework for websites and apps — like Bootstrap or Foundation, except every style and layout in it was gathered from real production sites instead of invented. Versioned with semantic versioning; currently v1.1.0.

The framework

gravel.css

The base stylesheet: design tokens, layout, link grids, box cards, list rows, admin forms.

gravel.js

Helpers for the data pattern: load a store, render rows, filter live, escape HTML, allow only safe URLs.

gravel-app.css / gravel-app.js

The app layer: app bar, bottom tab bar, bottom sheets, toasts, share sheet, haptics, photo input, a local store, and PWA templates (manifest + service worker).

The standard

Four layers every time: one canonical data store, one admin/editing pattern, one static client-rendered site pattern, one deploy pipeline.

Base + themes

Base

One core stylesheet shared across sites — the base is never forked. Variants are themes.

Purple theme

A directory theme layered on the base: deep purple brand color, hero search, category grids, gold featured badges, light + dark.

Dashboard theme

One theme for link hubs, feed readers and dashboards: dark topbar, white cards, filter chips, badges, and a plain-text mode.

Two halves

Gravel Web

One stylesheet and a handful of helpers: design tokens, a centered single-column layout, rectangle link grids, white box cards, list rows, admin forms. Static HTML, rendered client-side from one data store. No build step.

Gravel App

The app framework: an Android template standard (API 36, per-app release signing, local-first data with import/export) plus the web-app pattern — a sheet or KV store in, a Gravel page out, token-gated admin.

Gathered, not invented

The classic

The original house style: white boxes, lightgray borders, #f7f7f7 ground. Preserved verbatim as gravel-classic.css.

The base

The current standard core: ink #202428, accent #185e87, 780px column, big brand header, rectangle link buttons.

The card variant

A wider 980px wrap with rounded white boxes and a two-column card grid on desktop — folded into the themes rather than kept as a fork.

The app-like variant

12px radius cards, soft accent fills, KV-backed data with in-page editing — became the Dashboard theme.

The rule

Data lives in one canonical store — a spreadsheet, Cloudflare KV, or repo JSON — never hardcoded in HTML. Edit the sheet. Gravel does the rest.
