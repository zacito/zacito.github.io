Framework

Gravel

My reusable framework for websites and apps — like Bootstrap or Foundation, except every style and layout in it was gathered from my own live sites. Everything is built on Gravel.

The framework

GitHub repo (private) gravel.css gravel-classic.css gravel.js The standard Site inventory

Two halves

Gravel Web

One stylesheet and a handful of helpers: design tokens, a centered single-column layout, rectangle link grids, white box cards, list rows, admin forms. Static HTML, rendered client-side from one data store. No build step.

Gravel App

The app framework: the Android template standard (API 36, per-app release signing, local-first data with import/export) plus the web-app pattern — sheet or KV in, Gravel page out, token-gated admin.

Gathered from

Kato Life

The origin — its stylesheet opens with a block literally marked /*gravel*/: white boxes, lightgray borders, #f7f7f7 ground. Preserved as gravel-classic.css.

Cuhlur + this site

The current standard — identical core stylesheet on both: ink #202428, accent #185e87, 780px column, big brand header, rectangle link buttons.

kscmn.com

The card variant: navy #1e3a7d, 980px wrap, rounded white boxes, two-column card grid on desktop.

znet

The app-like variant: 12px radius cards, accent-soft fills, KV-backed data with in-page editing.

The rule

Data lives in one canonical store — a Google Sheet, Cloudflare KV, or repo JSON — never hardcoded in HTML. I edit the sheet. Gravel does the rest.
